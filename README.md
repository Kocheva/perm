# Карта проектных лидеров Пермского края

Статический сайт без бэкенда и внешних CDN. Интерфейс читает только `data/perm_leaders_map.json`.

Визуальная система основана на брендбуке Центра ГРАНИ. Логотип и Clear Sans находятся локально в `assets/`, поэтому внешний CDN не нужен.

В карточках персон публичная деятельность разделена по типам, роли снабжены счётчиками, а сайты и социальные сети организаций показаны в верхнем блоке. Служебные статусы данных пользователю не выводятся.

На главной темы и муниципалитеты ранжируют и выделяют персон. Страница темы содержит три набора персон, фильтры по роли и территории, практики с носителями, все проекты темы и отдельные подборки публичной деятельности.

## Локальный запуск

```bash
python -m http.server 8080 --directory .
```

Откройте `http://localhost:8080/`.

## Публикация

Содержимое папки можно положить в корень любого статического хостинга. Использованы hash-маршруты, поэтому дополнительная настройка перенаправлений не нужна.

## Важные правила данных

- В режиме «Организации» тема берётся из `organizations.primary_topic_id`.
- В режимах «Проекты» и «Финансирование» тема берётся из `projects.topic_id`.
- `grant_amount: null` не заменяется нулём.
- У руководителей отображаются проверенные проекты организаций через `person_project_links`, включая исходные цели проектов.
- Кандидаты и внутренние QC-листы в публичный JSON не включаются.

## Вкладка «Карта края»

Откройте `#/map` или выберите «Карта края» в шапке. Параметры после `?` сохраняют режим, муниципалитет и фильтры в ссылке. Контур региона находится в `assets/perm-krai.svg` (Natural Earth, слой states_provinces из QGIS). Карта работает с локальными файлами сайта.

В режимах проектов и организаций легенда использует соответственно `projects.topic_id` и `organizations.primary_topic_id`. Лента собирает уникальных людей через связи с выбранными проектами или организациями. В режиме ролей используются муниципалитет, роли и темы профиля человека. Один человек может входить в несколько ролей. Географические точки заданы в исходных данных, выноски и цвета ролей — в `regional-map.js`.
